Privasi formulir demo.

Versi: privacy-2026-10-14

Informasi ini menjelaskan pengolahan formulir demo pada build pengembangan StorePOS. Dokumen publik final, identitas badan usaha pengelola, kanal permintaan privasi, dan masa retensi data perlu ditetapkan sebelum rilis publik.

Data yang Anda kirim

Formulir meminta nama, nomor telepon Indonesia, nama usaha, jenis usaha, dan kota/kabupaten. Email, jumlah cabang, jumlah terminal, sistem saat ini, catatan, dan waktu dihubungi bersifat opsional.

Tujuan penggunaan

Data digunakan untuk menindaklanjuti permintaan dan menjadwalkan demo. Persetujuan informasi produk dipisahkan dari persetujuan demo, dan keduanya tidak dicentang secara otomatis.

Penyimpanan & perlindungan spam

Backend menyimpan permintaan demo dan versi persetujuan. Waktu pengiriman serta sumber halaman dicatat. Hash alamat IP digunakan untuk pembatasan permintaan. Nomor telepon dinormalisasi agar pengiriman berulang bisa dikenali.

Analytics

Build ini belum mengirim analytics ke penyedia pihak ketiga. Event interaksi di halaman hanya berisi jenis interaksi dan kategori pilihan. Nama, telepon, email, nama usaha, kota, serta catatan tidak dimasukkan dalam event analytics atau URL setelah pengiriman.

Permintaan mengenai data

Sebelum halaman dirilis ke publik, pengelola perlu menyediakan kanal yang jelas untuk permintaan akses, koreksi, penarikan persetujuan, dan penghapusan data. Informasi final akan menggantikan dokumen pengembangan ini.
