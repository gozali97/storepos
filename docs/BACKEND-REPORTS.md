# Fase 2.11 — laporan backend

## Sudah tersedia: pembayaran (CORE-037)

GET /api/v1/reports/payments?branch_id=UUID&from=YYYY-MM-DD&to=YYYY-MM-DD&user_id=UUID&format=json

user_id opsional; format csv untuk ekspor. Izin report.sales dan akses cabang diperlukan. Rentang maksimal 366 hari. Tanggal inklusif memakai zona cabang, termasuk batas tengah malam. Penerimaan berdasarkan payments.created_at (saat pembayaran manual disimpan), refund berdasarkan tanggal dokumen retur. Void/reversed tidak masuk penerimaan. Amount pembayaran tunai sudah neto dari kembalian, tidak dikurangi dua kali.

Baris per tanggal/jam lokal/pelaku/metode/verifikasi: received_cents, refunded_cents, net_cents sebagai string. Verifikasi refund manual ditandai MANUAL. JSON/CSV berasal dari query yang sama; ekspor dicatat audit. Lebih dari 100.000 hasil ditolak eksplisit sampai job ekspor latar tersedia.
